# TrainingCenter

항공정비 교육용 콘텐츠 통합 재생 프로그램 (**Aircraft Training Content Player**) 및 학습 자료 저장소입니다.

## 구성

| 폴더 | 설명 |
|------|------|
| `HydraulicSyatem/` | Visual Studio 2022 MFC 소스 프로젝트 |
| `Bin/` | 실행 파일 출력 위치 및 런타임 데이터 (Data, Pdf, Images, Progress) |
| `HydraulicSyatem/docs/` | 사용자 매뉴얼 (Word) |

## 빌드

1. Visual Studio 2022에서 `HydraulicSyatem/TrainingContentPlayer.sln` 열기
2. **Release \| x64** 빌드
3. `Bin/TrainingContentPlayer.exe` 생성

자세한 내용은 [HydraulicSyatem/README.md](HydraulicSyatem/README.md)를 참고하세요.
