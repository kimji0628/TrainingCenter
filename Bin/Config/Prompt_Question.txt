아래 PDF의 페이지별 내용을 바탕으로 4지선다 객관식 문제를 출제하세요.

[출제 조건]
- 문제 개수: {QUESTION_COUNT}개
- PDF 파일: {PDF_FILE}
- 페이지 범위: {PAGE_START} ~ {PAGE_END}
- 각 [PAGE:N] 블록의 내용에 근거한 문제만 출제
- 정답은 A, B, C, D 중 하나
- SOURCE_PAGE에는 해당 문제가 출제된 PDF 페이지 번호(정수)를 반드시 기록

[응답 형식]
반드시 아래 QSTART/QEND 블록 형식만 사용하세요. 다른 설명 문장은 포함하지 마세요.

QSTART
NO=1
CATEGORY=학습내용
SOURCE_PAGE=페이지번호
QUESTION=문제 본문
CHOICE1=선택지1
CHOICE2=선택지2
CHOICE3=선택지3
CHOICE4=선택지4
ANSWER=B
EXPLANATION=해설
QEND

A/B/C/D 또는 CHOICE1~4, EXPLAIN/EXPLANATION 형식도 허용됩니다.
SOURCE_PAGE는 반드시 [PAGE:N]에 해당하는 N 값이어야 합니다.
